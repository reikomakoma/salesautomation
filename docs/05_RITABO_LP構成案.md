## STEP 5. LPのストーリーライン(上から下への流れ)

LPは上から下へのストーリーテリングが重要。ここまでの回答を、読む人の気持ちの流れに沿って並べるとこうなる。

1. **「商談数が足りていますか?」**(Q1-2の悩みで入る)
   → 読者「まさにそれで困ってる」
2. **「営業代行、頼んだけど不満だった。ROIも合うか不安。わかります」**(悩みの深掘り)
   → 読者「そうそう、だから踏み切れない」
3. **「RITABOはアポ取りから受注後まで全部やります」**(Q2-2の一番の売り=解決策の提示)
   → 読者「全部やってくれるのか。でも本当にできるの?」
4. **「できる理由があります」**(Q2-1の根拠: 小松の経歴 / ハウスリスト3万件 / AIでform pilotを開発 / 鮮度の高いリストを自走で用意)
   → 読者「なるほど、体制と資産があるのか」
5. **「進め方はこうです」**(Q3-1の5ステップ)
   → 読者「イメージできた。うちの場合はどうなる?」
6. **「契約形態は固定・成果・常駐からフレキシブルに」**(ROIを合わせたい悩みへの答え)
   → 読者「うちの予算感でも相談できそう」
7. **「まずは無料相談で現状を聞かせてください」**(Q4-1のゴール=CTA)

ポイント: 各セクションは「前のセクションで生まれた読者の疑問に、次のセクションが答える」つながりにする。
